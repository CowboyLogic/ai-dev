# About AI Dev

## Purpose

AI Dev provides **practical configurations and working examples** for AI-powered development tools. It helps developers:

1. **Apply consistent patterns** across AI tools and models
2. **Share working configurations** with teams
3. **Integrate advanced capabilities** through MCP servers
4. **Start quickly** with copy-paste examples

For what the repository contains and how it is laid out, see the [home page](index.md) and the [README](https://github.com/CowboyLogic/ai-dev/blob/main/README.md).

## Philosophy

This repository emphasizes **examples over explanations**. It provides working configurations with links to authoritative documentation rather than rewriting vendor guides.

- **Action-oriented**: implement changes, don't just suggest them.
- **Example-first**: show concrete implementations.
- **Link to authority**: reference official documentation for concepts.
- **Documentation-aligned**: keep examples synchronized with the actual configurations.
